What you get

Two things that matter. One that's optional.

A small self-hosted stack: your notes synced to every device in near-real-time, and an API your agents/scripts can write into. No third-party cloud in the loop — notes are just Markdown files, forever.

🔄

Sync

One CouchDB container + the Self-hosted LiveSync plugin. Phone note → server → laptop, in seconds. This is the core of the stack.

🤖

Webhook for agents

A tiny endpoint any script or AI agent can POST to. It writes straight into the vault — instantly synced, no filesystem access needed.

Optional
🖥️

Browser access

Full desktop Obsidian streamed to any browser — for the odd time you want graph view from a machine that isn't yours. Off by default.

Setup · 5 minutes

Get sync running

This is all server-side — one `docker compose up`, then a quick plugin install on each device.

Clone and configure

Copy .env.example to .env and fill in a real COUCHDB_PASSWORD, WEB_PASSWORD and HOOK_TOKEN.

git clone https://github.com/Lyhack27/second-brain-stack
cd second-brain-stack
cp .env.example .env

Start the core

Just the two always-on services — sync and the webhook.

docker compose up -d couchdb hook

Install the plugin on each device

In Obsidian: install the community plugin Self-hosted LiveSync, point it at http://<your-server>:5984 (database obsidian, same user/password as .env).

First device pushes, the rest fetch

On the first device, let LiveSync push the vault. On every other device, choose "Fetch from remote" when the plugin asks.

That's it — notes now sync in near-real-time between every device, with CouchDB as the only server-side moving part.

The other half

Let agents write into the vault

Anything that can curl can add a note — no filesystem access, no UI needed.

curl -X POST http://<your-server>:8080/report \
  -H "Authorization: Bearer $HOOK_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"agent":"claude","title":"Nightly audit",
       "content":"Backups OK · SSL renews in 12 days"}'

This appends to Team/<agent>/<today>.md, writing a real LiveSync-format document straight into CouchDB — every device gets it instantly. Point a cron job, a CI step, or an AI agent at this and you have automated reports living in your second brain.

You don't need to touch Docker or bash yourself. Give one of these to a coding agent (Claude Code, or whatever you use) and let it do the work.

Make it a real second brain

Link notes into a real graph

Graph view is only interesting if notes actually link to each other. Whenever you write about a topic, add a [[Link]] to a hub note for that topic, and list the note back on the hub. A few minutes of linking turns a pile of files into a second brain.

Graph view → Filters → "Orphans" — turn it off to hide every note with zero connections and see just what's actually linked. Great for a live demo.
Optional

Browser access, when you need it

A full desktop Obsidian streamed to your browser — for plugin setup or editing from a machine that isn't yours. Sync and the webhook never need this running.

docker compose up -d obsidian   # turn on
docker compose stop obsidian    # turn off — sync never notices

Costs ~1GB RAM only while running. Log in at http://<your-server>:3000.

Gotchas we hit

⚠️

Bytes ≠ string length

LiveSync compares document sizes in UTF-8 bytes. Using JavaScript's .length (UTF-16) makes notes with accents or emoji look "corrupted" on other devices.

⚠️

Setup wizards flip your flags

The LiveSync plugin's setup dialogs can silently disable syncOnStart. Check the plugin's own settings if sync stops being automatic.

⚠️

CouchDB doc IDs need real percent-encoding

Querying CouchDB directly for a note in a subfolder? Encode the / in the doc ID as %2F — a literal slash gets parsed as a URL path separator, giving false "not found" errors.

⚠️

The webhook is the reliable path for automation

It writes straight to CouchDB — instant sync regardless of anything else running. A file dropped onto the vault folder on disk only syncs once the optional browser container happens to be open to notice it.

⚠️

Stale reverse-proxy configs haunt you

If you experiment with domains/routing, clean up unused Traefik/Caddy config — a forgotten rule claiming your domain shows up as random 502s weeks later.
